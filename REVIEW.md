# Review policy

Review changes against `spec.md`, `AGENTS.md`, `TODO.md`, the original `docs/reference/Rules.txt`, the v2 Visual Asset Bible and the checklist in `docs/reference/`.

Focus on:

- No fabricated live data, hidden sample fallback, unsupported claims or invented backend endpoints.
- Correct request/response paths from `docs/api-contract.md`, errors on unknown/non-JSON responses and no browser secrets.
- No false progress percentage, health/churn inference or source snippet substitution.
- Synchronized file-tree, graph, search, source and mode focus behavior.
- Keyboard access, useful labels, visible focus, responsive tabs, contrast and reduced-motion handling.
- Accurate privacy/terms caveats and owner-input placeholders; no invented address or custom domain.
- Supplied palette and artwork usage; no static image substituted for Cytoscape.
- Updated route manifest when routes change, and no stale docs or broken asset references.

Do not mark a requirement complete based only on code intent. Base completion on the delivered implementation and recorded build/route checks. Keep unresolved backend, domain, legal and contact items open in the project documentation.
